## Библиотека для удобной работы с iterable объектами

Необходимо реализовать библиотеку, которая предоставляет удобный API для работы с любыми iterable объектами. Библиотека должна поддерживать:

- методы-адаптеры (map, flatMap, filter и другие);
- методы-агрегаторы (sum, avg и другие);
- методы-коллекторы (collect, toArray и другие (подумайте, как сделать такое API расширяемым)).

Также библиотека должна поддерживать асинхронные iterable объекты. Работа с коллекциями должна быть ленивой и эффективной. Для структур данных, поддерживающих обход в обоих направлениях, должна быть возможность использования эффективной реализации модификатора reverse.

### Пример (ваш API может отличаться)

```js
const iter = intoIter(1000000).map((el) => el * el).limit(100).from(500);

const arr = iter.collect([]);
const arr2 = iter.reverse.collect([]);

const set = iter.collect(new Set());
const sum = iter.sum();
```
